# Images Folder

## Required Images

Please add the following images to this folder:

### 1. giuseppe-funaro.jpg
- Your professional headshot
- This will appear on the About page in the bio section
- Recommended size: 1000x1000px minimum
- Format: JPG or PNG

### 2. Logo (already included)
- `logo.svg` — the interlocking-rings mark, for light backgrounds (used in the navigation bar)
- `logo-light.svg` — lighter variant for dark backgrounds (used in the footer)
- `../favicon.svg` + `../apple-touch-icon.png` — the same mark, square-cropped, used as the browser icon

These are vector files, so they stay sharp at any size. Replace them in place if the
mark ever changes; no code changes are needed.

## How to Add Images

1. Save your headshot as `giuseppe-funaro.jpg` in this folder
2. Rebuild the project: `npm run build`
3. Push to GitHub to deploy
